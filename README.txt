IELTS Sprint PWA

1. Export a JSON backup from your current HTML app before switching.
2. Upload all five web files (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png) to the ROOT of a GitHub Pages repository.
3. Enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root).
4. Open the HTTPS Pages URL in Chrome on Android. Menu > Add to Home screen > Install.
5. Import your JSON backup in My Data. Local file storage does not transfer automatically to the hosted site.

Native Android home screen widgets are not included. A PWA can be installed as an icon, but a native widget requires an Android app or a compatible widget provider.
